# Petfolio — юридические документы

Этот репозиторий публикует статическую версию юридических документов приложения Petfolio через GitHub Pages.

**Файлы здесь генерируются автоматически из основного (приватного) репозитория Petfolio командой
`cd app && dart run tool/gen_legal.dart` и заливаются сюда скриптом публикации.**

**Руками не редактировать.** Любая ручная правка будет потеряна при следующей перегенерации и синхронизации,
а расхождение текста документа между приложением и этим сайтом — юридический дефект (несовпадение редакций
политики/условий, на которые пользователь давал согласие в приложении, с публично доступным текстом).

Источник правды — каталог `docs/legal/{ru,en}/*.md` в основном репозитории Petfolio.

## Структура

- корень — русская версия: `index.html`, `terms.html`, `privacy.html`, `consent_pd.html`, `consent_marketing.html`, `delete-account.html`;
- `en/` — международная версия: `index.html`, `terms.html`, `privacy.html`, `delete-account.html`.
